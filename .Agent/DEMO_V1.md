## v1.1：用户反馈与本轮施工

依据决策 D014 / D015，本轮修订 OW 网页首页及匿名公共数据的刷新流程：

- 保留最上方胜率 / 选取率 / 禁用率三项指标卡的原展示与样式，点击改为打开官方英雄榜来源。
- 移除全部英雄榜单区域、筛选 / 搜索 / 排序及英雄详情弹窗；原位置改为“更多信息 / 内容待补充”的高级信息占位。默认读取当前赛季竞技全部段位；清理旧筛选和详情 query。
- 近期增强 / 削弱 / 调整分别使用独立紧凑行，显示完整英雄名单；标题、来源日期和三行整体居中，头像增大，容器随内容收缩，窄屏或超长名单自然换行。
- 轮播保留视觉效果，文案采用“版本更新 / 活动资讯 / 社区动态”三类未来内容的简洁占位，标记示意配图，移除依赖英雄详情的操作按钮。
- 保留匿名公共数据读取、统计口径、来源日期、刷新及 CS2 / OW 隔离。数据库、账号、Overstats、KOOK 和公网发布仍不在本轮范围内，`miniprogram/` 禁改。
- 页面打开优先读取官方元数据与对应指标；可见期间定期检查，返回页面时检查更新。失败仅显示口径完全匹配且明确标旧的已有数据；无匹配数据时保留空 / 失败状态，不误用旧赛季。官方标签日期仍按源值展示，即使该日期较旧。

实际修改 `site/src/features/ow/OwHome.vue`、`ow.css`、`api.ts`、`types.ts`，新增 `site/scripts/check-ow-live.mjs` 与 `ow:check-live` 命令。公开数据源和现有快照保留；没有修改后端、数据库或发布到公网。

## v1 历史实现与验证（2026-10-08）

以下描述的是反馈修改前已通过本地验收的 v1，不代表 v1.1 的当前界面或验证状态。v1 的榜单、筛选、英雄详情和相关截图已被 D014 的首页需求取代。

### v1 范围

用户已启动基础网页 demo，先看视觉与使用体验，之后再加高级功能。实现免登录国服指标、三类官方近期调整、英雄头像、OW 独立配色与 CS2 / OW 切换；电脑与手机均适配。保留真实来源日期、多标签语义和已知职责冲突处理。

当前不实施数据库、账号、Overstats、KOOK 或生产部署；`miniprogram/` 禁改。旧蓝图仍是后续施工计划，不能当作本 demo 已交付的架构。

### v1 实现方式

- 主站保留 `site/src/CommunityApp.vue`，只增加游戏切换，旧查询参数链接继续走 CS2。
- OW 模块在 `site/src/features/ow/`，自己的类型、API、首页和 CSS。
- `site/public/ow-data/` 存实测公开快照，不存玩家资料；构建出的静态 demo 可直接读取。
- 开发期 Vite `/ow-live` 只读代理官方国服接口，前端带超时和业务校验；上游不可用时显示明确日期的快照。
- 官网浏览器 Origin 请求实测被拒；代理只用于本地开发，不代表已部署生产 OW API。
- 官方头像与立绘按配置调用，职责/调整图标来自官网；简单 UI 操作 SVG 自绘。旧开源 OW1 图标库覆盖不足，未作为当前英雄名单来源。

### 本地运行与公开快照

在当前前端工作树内：

```bash
cd /Users/lucas/.codex/worktrees/cd54/TrashBox/site
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

施工机器将原项目已安装依赖复制到本工作树 `site/node_modules`，未向原目录写依赖或缓存；Vite cache 放本工作树 `.run-local/ow-vite-cache`。后续其他环境可在 `site/` 常规安装依赖。

公开快照共 54 位英雄、11 个已验证筛选组合、540 行真实汇总数据。部分高段位英雄少于 54，保留实际记录数；源接口为空的翡翠/英杰未启用，不填造数据。运行 `npm run ow:check` 校验快照，`npm run ow:refresh` 手动重新采集（Node 22.18+，需要联网），完成后重新构建以更新静态版本。
