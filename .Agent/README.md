## 必须保留的边界

- 仅开发网页版和 KOOK 服务；手机浏览器属于网页范围。
- **禁止修改 `miniprogram/`，不开发微信小程序版。**
- CS2 与 OW 为主站中的两个明确板块，指标、搜索、图标和页面样式各自隔离。
- OW 公共英雄统计来自国服官网；个人对局来自 Overstats，两种统计人群不能混为一个榜单。
