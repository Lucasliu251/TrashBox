## 资格与数据边界

- 必须有有效 auth_account / 已验证国服战网身份 / 明确同步授权。任意 BattleTag、外部用户 ID 或图片相似度不能指定采集对象。
- 首次要求近期 OAuth 证明与源资料标签精确对应，再保存稳定源 ID；后续请求不反复使用过期昵称搜索。实际 OAuth 与大神返回字段对应关系尚未使用真实本人样本验证，异常保持拒绝。
- 在入队、源请求前、响应保存前检查所有权 / 授权版本 / 任务租约；解除、合并、暂停与旧租约的结果不能越权保存。不同用户同一场游戏分别保存本人记录，不从队友 / 对手名单扩展目标。
- 默认仅本人可见；暂停时隐藏且停止新增，存量仍归本人，重新开启可恢复。源故障保留已有有效记录，不删除或伪造指标。
- 只保存本人的胜负 / 时间 / 英雄 / 地图 / 职责 / 比分 / 消灭 / 助攻 / 死亡 / 伤害 / 治疗与源赛季；赛季命名空间与公开国服统计独立。不存全员名单、其他身份、头像、客户令牌、原始 payload。
- 上游默认 `ENABLE_DATABASE_WRITE=True` 会记录身份与完整对局，桥接强制禁用并启动时断言；请求日志与异常原文同样不输出。采用底层列表请求，不调用全员详情或渲染模块的相关网络流程。
- 私有回环地址 18081，HMAC / 60 秒请求有效期与 nonce 防重放；没有原生任意目标网页入口或 Nginx 公网代理。

## 接口与存储

`/api/v1/me/ow/status`、`/matches`、`/matches/{本地 UUID}`、`POST /sync`、`POST /sync-consent`。私人读接口解析站内 Cookie 会话，不接受旧 Bearer JWT 代替中央身份；写入沿用 CSRF / Origin 检查。对局详情按当前绑定所有权检查，本地 ID 不能转成任意上游查询。

迁移只新增 ow_bindings / ow_matches / ow_sync_jobs，绑定引用已验证身份，数据库唯一键按绑定 / 源对局去重。身份合并后的所有权随已验证身份解析，旧任务 account_id 不再有效；异步任务可恢复过期租约，但旧 worker 不能写入。

主动请求有一分钟节流 / 活跃任务去重，后台每五分钟扫描队列、约十五分钟将有效授权用户加入候选；每批最多二十任务，桥接单并发。上游来源通常为近期两个赛季，列表最多 48 条，不承诺全历史或固定完成时限。
